# Weather App

A weather app built with JavaScript, HTML, and CSS.

## Getting Started

```bash
git clone https://github.com/devhubasmr/Weather-App-With-Javascript.git
cd Weather-App-With-Javascript
```

Then open `index.html` in your browser.

## Tech Stack

- HTML
- CSS
- JavaScript
